# Mémoire commune Radar Steelbook

Cette mémoire est lue et mise à jour par **toutes les IA** qui travaillent sur Radar Steelbook (ChatGPT, Claude). Elle remplace la mémoire des conversations : une IA qui démarre une session ne sait rien, elle lit d'abord ce dossier.

## Avant de commencer (obligatoire)
Lire dans cet ordre : `PROJET.md` → `REGLES.md` → `TACHES.md` → les 10 dernières lignes de `JOURNAL.md`.

## Rôles
- **Antho** : donne les objectifs, les liens Amazon, publie lui-même sur TikTok et envoie lui-même les mails.
- **ChatGPT, directeur** : analyse, priorise, répartit les tâches, valide. Écrit les consignes dans `TACHES.md`.
- **Claude, développeur** : modifie les pages, fabrique les vidéos et carrousels, teste, corrige. Coche les tâches faites dans `TACHES.md`.
- **Contrôle qualité** : n'importe quelle IA relit le travail de l'autre avec `CHECKLIST_QUALITE.md` avant de dire que c'est fini.

## Règles de fonctionnement
1. Une seule consigne à la fois par tâche, écrite dans `TACHES.md` (qui, quoi, critère de fin).
2. Après chaque tâche : cocher dans `TACHES.md`, ajouter une ligne datée dans `JOURNAL.md`.
3. Ne jamais supprimer une règle de `REGLES.md` sans que Antho l'ait demandé. En cas de doute, demander à Antho.
4. Toujours récupérer la dernière version du dépôt avant de modifier un fichier.
5. **Le dépôt est public** : jamais de mot de passe, clé, e-mail, chiffre d'affaires ni donnée personnelle dans ce dossier.

## Limite à connaître
Les deux IA ne se parlent pas toutes seules : elles communiquent par ces fichiers. Pour passer la main à l'autre, Antho colle le lien du fichier (ou lui dit « lis la mémoire Radar Steelbook »).
